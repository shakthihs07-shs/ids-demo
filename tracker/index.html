This is a low-interaction honeypot (OpenCanary): the services only imitate real ones, and no attacker can get a shell or reach other systems. Privacy: IP addresses are personal data under GDPR, so the tracker stores only the country, the address without its last part and a hash that changes daily, never passwords, and deletes events after 30 days.
