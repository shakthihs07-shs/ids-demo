How it works

Loading the model card…

1. Flow features82 CICFlowMeter features per flow: sizes, timings, flags. IPs and ports are not used, so the model cannot memorise lab addresses.
2. Supervised modelGradient Boosting trained on Monday–Wednesday of CIC-IDS2017: DoS, Heartbleed, FTP/SSH brute force.
3. Anomaly layerIsolation Forest trained on benign traffic only. Flags the 5% least normal-looking flows, which catches attack types the supervised model never saw.
4. Decision bandsScore ≥ 0.7 → alert. Score 0.2–0.7 or anomaly → analyst review. Otherwise allow. From the project's human-in-the-loop tests.
Replayed traffic is real CIC-IDS2017 test data the model never trained on, compressed: attack flows are mixed with up to three times as many benign flows from the same days, and long quiet stretches are shortened, so attacks arrive far more often than in a real network. Scores are computed live by the server as each batch streams. Data: CIC-IDS2017 (Sharafaldin, Habibi Lashkari and Ghorbani, ICISSP 2018) with labels corrected by Engelen, Rimmer and Joosen (KU Leuven, WTMC 2021; Liu et al., CNS 2022).
